# 技能：子助手 A（现状基线与回归）

## 你的任务

把“现在系统到底能做什么”查清楚，并做成可重复的检查清单。

## 你负责什么

- 启动和关闭是否正常
- 服务是否能访问
- 文本同步是否正常（新增、删除、清空）
- 断网或连接失败时是否有兜底行为

## 你不能做什么

- 不改业务代码（除非主助手明确同意）
- 不改界面样式

## 你要产出什么

- 基线清单
- 最小回归检查步骤
- 回归结果报告

## 执行步骤

1. 先列出用户能感知到的核心行为。
2. 设计最小检查集合：启动、连接、提交、删除、清空、离线。
3. 每轮都复测并写出差异。
4. 差异要标注等级：严重问题或一般问题。

## 完成标准

- 核心路径都被覆盖
- 每轮都有可追踪结果

## 固定回报格式

```text
[子助手A回报]
基线用例：
- <编号>: <说明>
执行结果：
- 通过: <数量>
- 失败: <数量>
差异说明：
- ...
严重级别：
- 严重问题 | 一般问题
```
