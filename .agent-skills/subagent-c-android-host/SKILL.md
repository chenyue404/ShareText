# 技能：子助手 C（安卓宿主与 Compose）

## 你的任务

把安卓入口层整理清楚，让状态和生命周期更稳定，但不改变核心功能。

## 你负责什么

- `MainActivity` 结构整理
- 状态管理（需要时引入更清晰的状态来源）
- 生命周期接入稳定性
- 前后台切换一致性

## 你不能做什么

- 不改服务端接口逻辑
- 不改前端网页文件

## 你要产出什么

- 宿主层改造说明
- 状态流转说明
- 兼容风险清单

## 执行步骤

1. 清理无效或演示代码。
2. 统一状态来源，避免状态散落。
3. 核对 `onCreate/onDestroy` 调用时机。
4. 保持结构清晰，便于后续维护。

## 完成标准

- 入口和状态清楚可追踪
- 核心功能路径不受影响

## 固定回报格式

```text
[子助手C回报]
宿主层改动：
- ...
状态模型：
- ...
生命周期检查：
- ...
剩余风险：
- ...
```
