# 第4轮任务卡（主助手）

日期：2026-04-06
范围：仅修复两个已确认问题，不做扩展功能。

## 必修问题

1. App 首页地址显示为 127.0.0.1，应显示局域网可访问 IP。
2. 网页列表显示固定多个 null，数据渲染异常。

## 子助手分工

- 子助手B（服务端）：检查并修复 `/list` 输出数据格式与空值来源。
- 子助手C（安卓宿主）：修复本机地址获取逻辑，优先返回 Wi-Fi/局域网地址。
- 子助手D（网页端）：修复列表渲染，过滤异常空值并保持正常刷新。
- 子助手A（回归）：定义并执行最小回归（地址显示、网页列表、发送同步）。

## 通过标准

- App 首页显示可访问局域网地址（非 127.0.0.1，除非设备无网络）。
- 网页列表不再出现固定 null 垃圾项。
- 网页发送后，网页列表与 App 列表都能看到正确文本。
- `:app:assembleDebug` 通过。
