# 第5轮任务卡（主助手）

日期：2026-04-06  
范围：补齐 `origin/master` 的关键入口能力（不改核心业务逻辑）。

## 本轮目标

1. 支持从其他 App 通过“分享文本”直接导入到首页列表。
2. 支持在 App 内修改服务端口（1-65535），并让服务按新端口生效。
3. 首页地址展示要跟随端口变化。

## 暂不纳入（下轮再做）

1. 二维码页面。
2. 前台通知中的“扫码/停止”动作。
3. 完整设置页重建。

## 子助手分工

- 子助手A：分享入口迁移建议与边界分析。
- 子助手B：端口设置方案（校验/存储/重启/UI）建议。
- 子助手C：WebService 动态端口与并发安全建议。
- 子助手D：第5轮最小回归清单。

## 通过标准

1. 外部分享文本后，首页列表新增该文本。
2. 端口改为新值后，首页地址显示新端口，局域网可通过新端口访问。
3. 空端口、非法端口不会生效，并给出提示。
4. `:app:assembleDebug` 通过。
