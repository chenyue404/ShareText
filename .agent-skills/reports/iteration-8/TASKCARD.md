# 第8轮任务卡（主助手）

日期：2026-04-06  
范围：稳定性和可理解性收口，不扩展新业务。

## 本轮目标

1. 端口占用时给出明确提示（不要只提示“保存失败”）。
2. 服务启动失败时首页能看到异常状态和原因。
3. 设置页保存成功后自动返回首页，减少操作步骤。

## 子助手分工

- 子助手A：设置页错误提示文案与交互建议。
- 子助手B：端口占用检测最小实现方案。
- 子助手C：服务状态模型（RUNNING/STOPPED/ERROR）最小改造建议。
- 子助手D：第8轮回归清单。

## 通过标准

1. 端口被占用时，设置页明确提示“端口被占用”。
2. 服务启动失败时，首页可见异常状态/原因。
3. 保存成功后自动返回首页且新端口生效。
4. `:app:assembleDebug`、`:app:testDebugUnitTest` 通过。
