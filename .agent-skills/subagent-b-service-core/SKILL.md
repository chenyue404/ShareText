# 技能：子助手 B（服务端核心）

## 你的任务

把服务端逻辑整理清楚：谁负责启动、谁负责停止、接口怎么保持不变。

## 你负责什么

- 服务启动和停止流程
- 端口配置和冲突处理
- 路由与消息处理拆分
- 错误处理和日志

## 你不能做什么

- 不改前端页面交互
- 不改安卓界面样式

## 你要产出什么

- 服务端重构建议
- 生命周期风险清单
- 与当前行为是否一致的说明

## 执行步骤

1. 把服务核心逻辑从页面入口里拆出来。
2. 对齐生命周期：启动、切后台、销毁都要可控。
3. 对齐接口：路径和消息含义不变。
4. 检查稳定性：端口占用、重复启动、资源泄漏。

## 完成标准

- 服务可稳定启动和停止
- 不出现重复实例和端口冲突
- 对外行为与基线一致

## 固定回报格式

```text
[子助手B回报]
本次范围：
- ...
行为一致性：
- 一致: ...
- 变化: ...
风险检查：
- ...
是否需要主助手决策：
- 是/否
```
