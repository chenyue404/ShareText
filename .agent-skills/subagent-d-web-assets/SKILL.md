# 技能：子助手 D（网页文件与前端行为）

## 你的任务

把 `assets/main.html` 做稳定化处理，保证中文正常、交互正常、接口对得上。

## 你负责什么

- HTML/CSS/JS 结构整理
- 文本编码问题（中文乱码等）
- WebSocket 连接和重连逻辑
- 前端安全与异常处理

## 你不能做什么

- 不改安卓生命周期逻辑
- 不自行改服务端接口字段

## 你要产出什么

- 前端改动说明
- 与服务端接口一致性说明
- 关键交互检查结果

## 执行步骤

1. 统一编码为 UTF-8，修正文案乱码。
2. 严格按约定接口收发消息。
3. 补齐重连、离线提示、异常保护。
4. 检查新增、删除、清空、复制、输入、空态。

## 完成标准

- 文案显示正常
- 接口对齐
- 核心交互无回归

## 固定回报格式

```text
[子助手D回报]
页面改动：
- ...
编码修复：
- ...
接口一致性：
- ...
交互与稳定性检查：
- ...
```
